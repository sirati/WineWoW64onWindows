Wine 11 WoW64 on native Windows

The prototype keeps x86 application loading inside Wine while a native x64 Windows process hosts the guest. Linux MinGW-w64 cross-builds the host, Wine PE components and tests. GUI, ARM64 and additional NT services are out of scope.
