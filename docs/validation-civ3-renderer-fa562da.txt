Failures fixed on the way

- d8823fc: the runner read the bridge log while the bridge wrote it, died,
  and closed the bridge's stderr; wine-host.exe kept the runner's inherited
  output pipe, so the case never returned. c8af9f9 writes wine-host output
  to files, reads the log with shared access and ends wine-host if the
  runner stops early.
- c8af9f9: the bridge reported 0xc0000135 and stderr showed
  NATIVE_UNIXLIB_LOAD_FAILED ... civ3r_native.dll error=127, while the
  native control loaded the same DLL. The bridge imports opengl32, so Wine's
  opengl32 had loaded its x64 companion, installed as
  x86_64-native\opengl32.dll. Windows binds an import to any loaded module
  with that base name, so the renderer's opengl32 import resolved to the
  companion, which has no wgl exports. fa562da names native unixlibs
  <module>.so, as Wine's find_builtin_dll does, and still finds
  <module>.dll.
