Established fixes

The environment test crashed while inspecting startup parameters outside
Wine's heap. The bootstrap now calls Wine's original init_user_process_params
after loading the main image. Wine owns the final parameters, separate
environment allocation and directory initialization. Supplying the expected
startup directory buffer capacity removes its remaining length assertion.
All seven required exception checks and twelve focused notification, socket
and thread runs pass on the intermediate d1eea95 candidate.

The last Unicode mismatch used Windows' legacy l_intl.nls. Supplying pinned
Wine l_intl.nls through the existing NLS storage adapter fixes U+037F to
U+03F3 without changing Wine's string/case algorithms.
