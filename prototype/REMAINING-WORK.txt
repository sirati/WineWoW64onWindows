Remaining runtime work

The accepted baseline and focused results are recorded in README.txt and
the Luna evidence bundles. Forced-termination wait races remain under
investigation. This table distinguishes those failures from verified controls.
Difficulty is for this prototype, not for full Wine.

| Area | Current result | Likely fix | Difficulty |
|---|---|---|---|
| Additional XSTATE components | Native plus ten Wine runs on 3b0e299 pass remote context round trips, APC delivery and exception-handler context edits for AVX, opmask, ZMM_Hi256 and Hi16_ZMM. | Enabled vector components are covered on this hardware. Other feature types require separate controls when exposed. | Passed for tested components |
| Fiber overflow recovery | The baseline `6e6acd8` crashed on all ten Wine runs. Nix `758da9f` passes native plus ten Wine runs for both fiber fixtures. | The Nix `758da9f` stack adapter passes native plus ten Wine fiber-overflow and fiber-switching runs, including reservation release. Further custom-stack behavior needs separate controls. | Medium |
| Forced dynamic-code policy | d34a200 maps bootstrap DLLs as SEC_IMAGE and modifies data only. With dynamic=1, hello32, ten runtime cases and six unmodified-application commands pass, including C++/SEH, APC/IOCP, threads, callbacks, AVX, fiber overflow, Lua, 7za and SQLite. Archive hashes match. | Tested paths are covered. Applications that generate or modify executable code remain subject to the Windows policy, as native applications are. | Passed for tested scope |
| CET/shadow-stack policy | CET and CET-strict fail at Wine IRETQ with c0000409 and fast-fail 0x39. NtContinue stays in CS33; RtlRestoreContext enters CS23 only without CET. Far-jump controls require a low SSP and trap before the first guest instruction with TF. See docs/cet-investigation.txt. | Adapt context restoration and shadow-stack state together, preserving HIGH_ENTROPY_VA and debugger semantics. Native fiber allocation and thread ZeroBits did not independently produce low SSPs. | High |
| Bootstrap and main EXE canonical-address collision | Wine's original relocator provides the bootstrap fallback. A separate main EXE omission reproduced eight baseline crashes; all eight fixed runs passed with confirmed Wine relocation on 4d17741. See docs/loader-relocation-regression.txt. | Main relocation now runs after PEB image selection, before imports or callbacks. Full candidate regression is pending. Dynamic-code prohibition still disallows required executable rewriting. | Focused fix verified |
| Provider-specific Winsock controls | Standard TCP/UDP, DNS, poll/event, overlapped, IOCP, AcceptEx, ConnectEx, TransmitFile and WSARecvMsg IP_PKTINFO pass. Unknown provider ioctls return `STATUS_NOT_SUPPORTED`. | Add one native control adapter at a time with a matching 32-bit marshalling test. | Medium per control |
| Forced issuer termination | The --spin control, with readiness published after adapter return, prints success in native plus thirty Wine runs. The initial harness omitted numeric exits. The mode that races entry into a wait adapter hung in one of twenty runs on 0b00a82 and five of twenty on 3b0e299. | Collect native timeout stacks and repeat the safe control with numeric exits. Determine whether the race terminates an owner of an adapter or heap lock before changing the runtime. | Under investigation |
| Concurrent thread-context lifetime | Thread-record references did not retain the CPU/TEB/stack allocation after native exit. The adapter now releases that storage with its final record reference. | New thread_exit_context32 races context queries against suspended-thread termination across 64 lifetimes; native control and stress validation are pending. | Candidate implemented |
| Extended APCEx2/reserve-object variants | Basic, initial suspended-thread, nested, alertable and I/O completion APC paths pass. APCEx2 reserve-object combinations are additional services outside the current scope. | Reuse Wine's APC frame and continuation code, then add native reserve-object bookkeeping. | Medium |
| Less common thread information classes | Guest thread enumeration, TLS clearing, suspended creation and remote context subset pass. Other thread information classes are not mapped. | Add mappings only where an application needs them, using Wine's existing 32-bit structures. | Low to medium |
| C++ nested returning-helper diagnostic | The focused nested-return diagnostic still fails in stock Wine 11 as well as the port. Normal catches, rethrow, destructor cleanup, worker exceptions and SEH pass. | First reproduce with a current upstream Wine build, then decide whether the test is invalid or needs a Wine exception-frame fix. | Unknown |
| Broader unmodified applications | 7-Zip, Lua, SQLite, BusyBox and 7zr controls pass through Wine's loader. Universal application compatibility is not established. | Expand the corpus by DLL family and loader behavior. | High |
| GUI, ARM64, additional NT services | Out of scope by request. | No work in this phase. | Excluded |
